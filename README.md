# ALE — Μηχανή Προσαρμοστικής Μάθησης

Προσωπική πλατφόρμα μελέτης για τις ασφαλιστικές εξετάσεις (3 Οκτωβρίου 2026).
Στατική εφαρμογή HTML/CSS/JS — χωρίς backend, χωρίς build.

## Διάταξη

Η εφαρμογή έχει σταθερό «κέλυφος» με τρεις ζώνες που προσαρμόζονται στο πλάτος
της οθόνης: κάτω μπάρα πλοήγησης + συρόμενο πλευρικό μενού κάτω από 768px,
στενή κάθετη λωρίδα με εικονίδια από 768px, και πλήρες πλευρικό μενού (με
δυνατότητα σύμπτυξης σε λωρίδα, η επιλογή θυμάται) από 1024px και πάνω. Κάθε
προβολή έχει ενιαία επικεφαλίδα (τίτλος, προαιρετικός υπότιτλος, κουμπί
επιστροφής και ενέργειες) μέσω του κοινού `pageHeader()`.

## Τοπική εκτέλεση

    python -m http.server 8000

Άνοιξε http://localhost:8000 (το άνοιγμα του index.html απευθείας ΔΕΝ δουλεύει —
τα JSON της ύλης θέλουν server).

## Ανάπτυξη στο GitHub Pages

1. `gh repo create ALE --private --source . --push` (ή δημιουργία repo + push χειροκίνητα)
2. GitHub → Settings → Pages → Source: `main`, φάκελος `/ (root)` → Save
3. Η εφαρμογή σερβίρεται στο `https://<username>.github.io/ALE/`

**Σημείωση:** ιδιωτικά repos έχουν Pages μόνο με GitHub Pro. Εναλλακτικά: δημόσιο repo
(η ύλη είναι δημόσια ορατή) ή Cloudflare Pages / Netlify (δωρεάν, ιδιωτικό repo).

## Εγκατάσταση σε iPhone/iPad

1. Άνοιξε το URL στο Safari
2. Κουμπί Κοινοποίησης → «Προσθήκη στην οθόνη Αφετηρίας»
3. Η εφαρμογή δουλεύει και offline μετά την πρώτη φόρτωση

## Συγχρονισμός συσκευών

Ρυθμίσεις → «Κοινοποίηση προόδου» (share sheet / AirDrop, όπου υποστηρίζεται) ή
«Εξαγωγή προόδου» (κατεβάζει JSON) → άνοιξε/στείλε το αρχείο στην άλλη συσκευή →
Ρυθμίσεις → Εισαγωγή προόδου. Η συγχώνευση κρατά πάντα το πιο πρόσφατο ανά θέμα
και τα μέγιστα στατιστικά.

## Εξέταση εκθέσεων και τράπεζα θεμάτων

Το πραγματικό δοκίμιο του Κλάδου Ζωής είναι **8 ερωτήσεις έκθεσης, από τις οποίες
απαντάς τις 6** — δεν έχει ερωτήσεις πολλαπλής επιλογής. Δύο οθόνες καλύπτουν αυτό:

- **📝 Εξέταση εκθέσεων (6 από 8)** — παράγει δοκίμιο με τη δομή του πραγματικού:
  πρώτη πάντα η ερώτηση για τις ανάγκες που καλύπτει η ασφάλιση Ζωής (9/9 δοκίμια),
  τελευταία πάντα οι τρεις σύντομοι ορισμοί, και τα ενδιάμεσα θέματα κληρώνονται
  σταθμισμένα με τη συχνότητα εμφάνισής τους. Γράφεις την απάντηση, μετά
  αυτοδιορθώνεσαι σημειώνοντας ποια σημεία κάλυψες σε σχέση με το υπόδειγμα.
  Η βαθμολογία δοκιμίου μετρά τα αναπάντητα θέματα ως μηδέν, όπως το πραγματικό
  δοκίμιο· η «μέση ποιότητα απαντήσεων» δείχνει χωριστά πόσο καλά απάντησες σε ό,τι
  επιχείρησες.
- **📚 Τράπεζα θεμάτων** — και οι 18 επαναλαμβανόμενες ερωτήσεις με τη συχνότητά
  τους, κάθε παραλλαγή της εκφώνησης, τα σημεία βαθμολόγησης και υπόδειγμα απάντησης.

Η τράπεζα ζει στο `data/<course>/essay-bank.json` και η ανάλυση στο
`exam-analysis.json`. Μετά από αλλαγή στην τράπεζα:
`python scripts/validate-essay-bank.py` από τη ρίζα του repo.

Τα προχειρόγραφα των εκθέσεων μένουν στο `ale.essay.v1` στη συσκευή και **δεν**
μπαίνουν στο αρχείο συγχρονισμού προόδου.

## Ενημέρωση ύλης

Η ύλη ζει σε `data/<course>/content.json` και παράγεται από το Claude Code από τα
αρχεία ύλης (PDF/DOCX). Μετά από κάθε ενημέρωση ύλης: bump το `CACHE` στο `sw.js`
(π.χ. `ale-v2`) και push.

## Επεξεργασία ύλης από την εφαρμογή

Οι αλλαγές στην ύλη (μορφοποίηση, διορθώσεις) γίνονται μέσα από την εφαρμογή
και αποθηκεύονται μόνιμα στο αρχείο `data/<μάθημα>/content.json` αυτού του
αποθετηρίου. Χρειάζεται ένα GitHub token **μία φορά ανά συσκευή**:

1. Άνοιξε github.com → Settings → Developer settings →
   **Fine-grained personal access tokens** → Generate new token.
2. Resource owner: ο λογαριασμός σου. **Repository access: Only select
   repositories → ConstantinosO/ALE** (μόνο αυτό).
3. Permissions → Repository permissions → **Contents: Read and write**.
   Τίποτα άλλο.
4. Expiration: ό,τι προτιμάς (π.χ. 1 έτος). Generate & αντίγραψε το token.
5. Στην εφαρμογή: Ρυθμίσεις → «Επεξεργασία ύλης» → επικόλλησε το token →
   Αποθήκευση → Έλεγχος σύνδεσης.

Χωρίς token η εφαρμογή λειτουργεί κανονικά, απλώς χωρίς κουμπιά ✏️ —
ασφαλής για να τη μοιραστείς με άλλον μαθητή. Το token μένει μόνο στη
συσκευή (localStorage) και δεν μπαίνει ποτέ στα αρχεία συγχρονισμού προόδου.
